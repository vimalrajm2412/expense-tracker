# PocketLedger

PocketLedger is a personal finance web app for tracking income, expenses, and monthly budgets.

## What It Does

- Creates a local account on the device
- Stores all data directly in the browser
- Adds, edits, and deletes transactions
- Tracks both income and expenses
- Organizes records by category, date, tags, and notes
- Supports recurring transaction flags
- Excludes selected entries from budget calculations
- Shows dashboard summaries for spending, income, savings, and budget balance
- Displays recent transactions and top spending categories
- Provides calendar-based transaction viewing
- Supports search and filter by keyword, category, type, date range, and amount
- Exports filtered transactions as CSV
- Exports account data as JSON
- Generates a printable expense report
- Supports install as a mobile or desktop PWA
- Works offline after loading

## Main Screens

- Authentication
- Dashboard
- Calendar
- Analytics
- Search
- Settings

## Data Stored

- Account details
- Profile name
- Theme preference
- Monthly budget
- Transaction history

## Platform Support

- Mobile browsers
- Desktop browsers
- Installed PWA on supported devices
